# Earlier Streamlit prototype

This folder holds the first SafeSow prototype, built in Streamlit during the hackathon. It is kept as a backup:
https://warpdrive-spaceapps.streamlit.app

**The final app is [`../index.html`](../index.html)**, published with GitHub Pages:
https://milkyway3257.github.io/Warpdrive-spaceapps-2026/

Run the prototype locally: `pip install -r ../requirements.txt` then `streamlit run streamlit_app.py`.
