# WARPDRIVE — Field Shift: Adapting Farms with NASA Data

**NASA Space Apps Challenge 2026 · Local Event: Guayaquil, Ecuador**

Team WARPDRIVE is building a decision-support tool that combines NASA Earth observations with local soil information, crop characteristics and farmer priorities to help farmers in coastal Ecuador explore crop-rotation strategies that protect soil health and adapt to changing weather and water conditions.

> 🚧 Work in progress during the hackathon (14–15 November 2026). This README will be updated with the final project description, demo link and instructions.

## Repository structure

| Folder | Contents |
|---|---|
| `app/` | Application code (Streamlit) |
| `data/` | NASA and soil data (CSV) and the scripts that download them |
| `docs/` | Constitution, specification, data dictionary, rotation rules, glossary |
| `media/` | Images and video for the pitch |

## NASA data used (so far)

- **NASA POWER** (Prediction Of Worldwide Energy Resources), AG community, 2001–2025 monthly climatology: air temperature, daily temperature range, precipitation, top-of-atmosphere radiation, relative humidity, root-zone soil wetness.

More datasets (e.g. MODIS NDVI, NASADEM elevation, SMAP soil moisture, GPM IMERG precipitation) will be listed here as they are integrated.
